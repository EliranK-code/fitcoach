# תפריט לדוגמה בשיטת כף היד (יום רגיל)

התפריט מתאים לרוב המתאמנים. מתאימים כמויות לפי כף היד ולפי המטרה. אין מאכלים אסורים, יש מנות.

## ארוחת בוקר
- 2-3 ביצים (או שקשוקה) או יוגורט חלבון עם גרנולה
- 1-2 פרוסות לחם מלא
- ירקות חתוכים: עגבנייה, מלפפון, פלפל
- כף טחינה או רבע אבוקדו

## ארוחת צהריים
- חזה עוף / דג / קציצות הודו / טופו: כף יד אחת או שתיים
- אורז, בטטה או פתיתים: כף יד קעורה אחת או שתיים
- סלט גדול או ירקות מבושלים: חצי צלחת
- כף שמן זית בסלט

## ביניים
- פרי + חופן אגוזים
- או: קוטג' עם קרקרים מלאים
- או: שייק חלבון עם בננה (בימים עמוסים)

## ארוחת ערב
- טונה / ביצים / גבינה לבנה / קטניות: כף יד אחת או שתיים
- ירקות או מרק ירקות
- פחמימה: מנה אחת (או חצי מנה בתקופת ירידה במשקל)

## טיפים
- להכין מראש חלבון ל-2-3 ימים (עוף בתנור, ביצים קשות, קטניות מבושלות)
- לשתות כוס מים לפני כל ארוחה
- ארוחה בחוץ: לבחור מנה עם מקור חלבון ברור, להוסיף סלט, ולהנות בלי רגשות אשמה
